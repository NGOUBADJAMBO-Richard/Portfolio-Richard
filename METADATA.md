## 🌐 Internationalisation (i18n)

### Langues Supportées

- **Français** (FR) - Défaut
- **Anglais** (EN)

### Implémentation

- Objet `i18n` avec clés hiérarchiques
- Attributs `data-i18n` sur éléments HTML
- Toggle en navbar (EN/FR)
- LocalStorage pour persistance

### Exemple Structure

```javascript
const i18n = {
  fr: {
    "nav.about": "À propos",
    "hero.title": "Ingénieur Fullstack & Mobile",
    "contact.cta": "✉ Me contacter",
  },
  en: {
    "nav.about": "About",
    "hero.title": "Fullstack & Mobile Engineer",
    "contact.cta": "✉ Contact me",
  },
};
```

## 🌙 Thème Clair/Sombre

### Implémentation

- Mode par défaut: **Dark**
- Stockage: **LocalStorage** (`theme`)
- Attribut racine: `data-theme="dark"` ou `data-theme="light"`
- Transition: 0.4s entre les thèmes
- Variables CSS: Changent selon le thème

### Variables Utilisées

```css
var(--bg)         /* Background */
var(--surface)    /* Cards */
var(--text)       /* Texte principal */
var(--text2)      /* Texte secondaire */
var(--accent)     /* Actions principales */
var(--accent2)    /* Actions secondaires */
var(--border)     /* Bordures */
```
